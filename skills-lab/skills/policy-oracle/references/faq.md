# Customer FAQ

This file is a local FAQ source for the `policy-oracle` skills-lab test.

## Order changes

- Customers may request an order change before the order is packed.
- Order changes are not guaranteed after packing has started.
- Customers should ask for a human teammate as soon as possible when they need to change an order.

## Address changes

- Customers may request a shipping address change before the order is packed.
- Address changes are not guaranteed after packing has started.
- Customers should ask for a human teammate as soon as possible when they need to change a shipping address.

## Cancellations

- Customers may request cancellation before the order is packed.
- Cancellations are not guaranteed after packing has started.
- If cancellation is not possible, the customer may follow the returns policy after delivery.

## Order tracking

- Tracking information is sent after the order ships.
- If tracking has not arrived after the order ships, the customer should ask a human teammate to check the order.

## Gift wrapping

- Gift wrapping is not available at this time.

## Warranty

- DeskClaw provides a 30-day limited warranty for manufacturing defects starting from the delivery date.
- The warranty covers defects in materials or workmanship.
- The warranty does not cover normal wear, misuse, accidental damage, or damage caused by improper care.
- Customers should provide their order number and clear photos when asking about a warranty issue.

## Unsupported FAQ details

- The available FAQ does not list accepted payment methods.
- The available FAQ does not mention loyalty points.
- The available FAQ does not mention wholesale pricing.
